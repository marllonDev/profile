# Portfolio Marllon Zucolotto

Portfólio pessoal e apresentação — HTML, CSS e JavaScript puro.

## 🚀 Sobre

Engenheiro de Dados focado em **pipelines, Big Data e IA aplicada**. 

Trabalho com **Claude Code**, **OpenRouter**, **MCP** e ferramentas modernas de engenharia de dados.

## 🌐 Deploy

O site é deployado automaticamente via **GitHub Pages** a cada push para `main`.

**URL**: https://marllonDev.github.io/profile

## 📁 Estrutura

```
.
├── perfil.html        # Página principal
├── perfil.css         # Estilos (tema claro/escuro)
├── perfil.js          # Efeitos (digitação, animações)
├── style.css          # Estilos adicionais
└── assets/
    └── perfil.jpeg    # Foto do perfil
```

## 🔄 GitHub Actions

- **Validação**: HTML lint via `tidy`
- **Deploy**: Automático para GitHub Pages em cada push

## ⚙️ Configuração Local

Nenhuma dependência! Abra `perfil.html` no navegador ou rode um servidor local:

```bash
python3 -m http.server 8000
# Acesse http://localhost:8000
```
